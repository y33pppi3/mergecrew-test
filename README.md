# mergecrew-test

Test project for Mergecrew multi-agent SDLC pipeline.

## Tech Stack
- Node.js 22+
- Native HTTP (no frameworks — simple and fast)

## Development
```bash
npm start
npm test
```

## Pipeline
This project is managed by Mergecrew multi-agent team:
- **Planner** → breaks down requirements
- **Coder** → implements features
- **Reviewer** → validates code quality
- **Runner** → builds and tests
